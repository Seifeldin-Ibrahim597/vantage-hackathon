# Team Vantage

This repository is a React + TypeScript app built with Vite and hosted on Vercel.

- Install with `npm ci`. Start locally with `npm run dev`.
- Keep new work small and focused on the team's task.
- Run `npm run check` and `npm run build` before a handoff.
- Keep the UI responsive and keyboard accessible.
- Never commit `.env` files, secrets, `.vercel`, `node_modules`, or `dist`.
- Add backend services only when a feature needs them; this starter has none.
- Update README when setup or deployment changes.
